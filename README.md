# Photo Recipe Studio

Assistant photo web : analyse d'image, détection de sujets, presets personnalisés, aperçu avant/après, masques locaux guidés, galerie cloud et comptes Supabase.

## Déploiement

Le site est statique et prévu pour GitHub Pages. Le fichier `index.html` contient l'interface, le style et la logique de la version publiée.

## Backend

Le frontend est déjà relié au projet Supabase configuré pour :
- authentification utilisateur,
- profils,
- galerie privée,
- stockage photo,
- rôle administrateur,
- règles RLS.
